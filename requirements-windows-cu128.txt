# Windows + NVIDIA Blackwell (RTX 50-series) variant of requirements.txt.
#
# Use this INSTEAD of requirements.txt on Windows with an RTX 50-series GPU.
# requirements.txt targets the Linux cluster and is unchanged; three of its
# pins cannot work in this combination:
#
#   * torch==2.5.1+cu121 does not support Blackwell. Consumer RTX 50-series
#     cards report compute capability 12.0 (sm_120); CUDA 12.1 builds stop at
#     sm_90, so that wheel installs cleanly and then fails at run time with
#     "no kernel image is available for execution on the device". cu128 builds
#     start at torch 2.7.0, and 2.7.1 is the closest to the pinned 2.5.1.
#
#   * triton==3.1.0 has no Windows wheel at all (PyPI ships 5 files, none
#     win_amd64). It is a Linux-only dependency of torch and is not needed here.
#
#   * sympy is bumped 1.13.1 -> 1.13.3, the minimum torch 2.7.1 accepts
#     (sympy>=1.13.3). Pure-python package, no other pin depends on it.
#
#   * The nvidia-*-cu12 pins are CUDA 12.1 component versions and would
#     conflict with a cu128 torch. Windows torch wheels bundle their own CUDA
#     runtime, so the components are not installed separately.
#
# Everything else is pinned identically to requirements.txt. Python 3.12 is the
# safe choice: every pinned package publishes a cp312 win_amd64 wheel.
#
#   conda create -n GPU python=3.12 -y
#   conda run -n GPU python -m pip install -r requirements-windows-cu128.txt
